HAPTIC

사용자만 느끼는 신호

모드별 리듬과 우선순위로 헷갈리지 않게 안내합니다.

여러 모드가 동시에 켜져 있어도 SYNORA는 모든 신호를 한꺼번에 보내지 않습니다. 상황의 중요도에 따라 하나의 핵심 신호만 선택해 전달합니다.

진동 세기 조절

미세 조정

모드별 진동 리듬

모드마다 리듬과 감각이 다르게 설계되어 동시에 켜져 있어도 더 쉽게 구분할 수 있습니다.

대화 흐름 모드

말할 타이밍과 질문 타이밍을 빠르게 알아차릴 수 있도록 짧고 분명한 진동으로 안내합니다.

짧고 또렷한 진동
리듬 · 짧은 펄스 강도 · 중간 이상 우선 · 2순위
  • 짧게 1번지금 반응 가능
  • 짧게 2번질문하거나 확인 가능
  • 짧게 3번대화 속도가 빨라짐

짧은 펄스가 또렷하게 끊겨서 보이도록 미리보기 됩니다.

감각 안정 모드

소음, 말소리 겹침, 피로 누적처럼 감각 부담이 커지는 상황을 부드럽게 반복되는 진동으로 알려줍니다.

부드럽고 반복적인 진동
리듬 · 반복 웨이브 강도 · 낮게 시작 우선 · 1순위
  • 약하게 반복주변 자극 증가
  • 약하게 빠른 반복여러 말소리 겹침
  • 천천히 반복휴식 필요 가능성

부드러운 웨이브가 반복되며 긴장을 낮추는 흐름으로 보입니다.

사회 환경 적응 모드

표정 변화, 목소리 톤 변화, 분위기 변화 가능성을 단정하지 않고 짧은 진동 뒤 잔잔한 여운으로 알려줍니다.

짧은 진동 뒤 약한 여운
리듬 · 펄스 뒤 여운 강도 · 낮고 잔잔함 우선 · 3순위
  • 짧게 1번 + 약한 여운상대 반응 변화 가능성
  • 짧게 2번 + 약한 여운말투 변화 가능성
  • 부드럽게 길어지는 1번확인 질문 필요 가능성

짧은 펄스 뒤에 잔잔한 여운이 남는 형태로 미리보기 됩니다.

신호 우선순위

여러 신호가 동시에 감지될 경우, 사용자의 부담을 줄이기 위해 가장 중요한 신호 하나만 전달합니다.
1순위 감각 안정 모드

과부하와 휴식 필요는 사용자의 상태와 직접 연결되기 때문에 가장 먼저 안내합니다.

2순위 대화 흐름 모드

대화 참여 타이밍을 놓치지 않도록 필요한 순간에 안내합니다.

3순위 사회 환경 적응 모드

표정과 분위기 변화는 보조 신호로 전달해 상황을 차분하게 확인할 수 있도록 돕습니다.

조작과 알림은 다르게

사용자가 안경에 보내는 명령과 안경이 사용자에게 주는 알림은 서로 다른 리듬으로 구분됩니다.
사용자 조작
  • 두 번 탭모드 전환
  • 앞뒤로 쓸기진동 세기 조절
  • 3초 길게 누르기휴식 요청 실행
  • 5초 길게 누르기기능 일시 정지
안경의 진동 알림
  • 짧고 또렷한 진동대화 흐름 안내
  • 부드러운 반복 진동감각 안정 안내
  • 여운이 남는 진동사회 환경 변화 안내

길게 누르기는 사용자가 안경에게 보내는 명령이고, 반복 진동은 안경이 사용자에게 보내는 알림입니다.
